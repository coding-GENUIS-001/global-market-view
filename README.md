# Global Market View

A dark trading-style dashboard for viewing world currencies, markets, companies, and portfolio performance.

## Features
- Global FX rate overview
- Stocks, crypto, and indices panel
- Market news and company cards
- Dark trading terminal aesthetics
- Read-only, view-only experience

## Tech stack
- Next.js
- TypeScript
- Tailwind CSS

## Run locally
```bash
npm install
npm run dev
```

Then open http://localhost:3000
